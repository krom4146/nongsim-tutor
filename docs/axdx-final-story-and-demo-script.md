# AXDX 본선 공통 스토리 1장 + 시연영상 장면별 대본

## 1. 공통 스토리 1장

### 제목

**교육이 끝난 뒤에도 성과가 이어지게 — NH 농심튜터**

### 한 문장 정의

NH 농심튜터는 교육생의 **입교 전 목표, 교육 중 참여, 수료 성찰, 현업 미션, 2개월 후 적용 결과**를 하나의 데이터 흐름으로 연결하고, AI가 그 근거를 정리해 교수요원의 교육 운영과 후속 지원을 돕는 교육 전이 관리 도구입니다.

### 우리가 해결하려는 문제

기존 교육에서는 목표 설문, 수업 중 답변, 팀 장표, 수료 소감, 사후 설문이 서로 다른 순간과 문서에 흩어집니다. 교수요원은 교육생의 많은 응답을 수업 중 즉시 읽기 어렵고, 교육생은 입교 때 세운 목표를 수료 후 행동으로 이어가기 어렵습니다. 결국 “교육을 잘 진행했는가”는 알 수 있어도, **무엇을 배웠고 현업에서 어떻게 적용했는가**는 추적하기 어렵습니다.

### 해결 방식

농심튜터는 교육의 시간을 다음 다섯 단계로 연결합니다.

> **입교 전 목표 → 교육 중 참여 → 수료 성찰 → 현업 미션 → 2개월 후 적용**

1. 교육생은 입교 전 세 질문에 답하고, AI의 도움으로 자신의 목표 다짐문을 만듭니다.
2. 수업 중에는 질문 응답과 팀 장표가 축적됩니다. AI는 답변을 주제별로 묶고 원문 근거와 후속질문을 제안하며, 장표의 핵심 주장과 실행 방향을 정리합니다.
3. 신규직원은 실제 보고 상황을 연습하고 AI 피드백으로 보고의 구조와 보완점을 확인합니다.
4. 수료일에는 입교 전 목표를 다시 보며 성찰하고, AI가 ‘언제·무엇을·어떻게’가 포함된 2주 현업 미션을 제안합니다.
5. 교육 2개월 후에는 익명 현업활용도 조사를 통해 적용 수준, 장애요인, 적용 사례와 필요한 지원을 수집하고 전이 리포트로 확인합니다.

### AI가 맡는 역할과 맡지 않는 역할

AI는 교육생을 평가하거나 교수요원의 판단을 대신하지 않습니다. 교육생이 실제로 남긴 답변과 장표를 근거로 **정리·묶기·질문하기·행동계획 만들기**를 돕습니다. 분석 화면에는 실제 AI·캐시 상태와 교수요원 검토 안내를 표시하고, 근거형 분석은 원문 식별자를 검증합니다. 개인정보는 분석·내보내기에서 제외하고, 오류가 발생하면 임의의 시연 결과로 바꾸지 않고 오류 안내와 재시도를 제공합니다.

### 사용자별 가치

- **교육생:** 교육 전 목표가 수료 성찰과 현업 행동으로 이어져 ‘나의 학습 여정’이 남습니다.
- **교수요원:** 많은 답변 속 공통점·오개념·후속질문을 필요한 순간에 확인하고 수업에 개입할 수 있습니다.
- **교육 조직:** 과정별 목표·참여·성찰·현업 적용 데이터를 축적해 다음 교육과 현업 지원을 개선할 수 있습니다.

### 차별점

이 구현물의 핵심은 AI 기능의 개수가 아니라, **한 번의 AI 답변이 교육 전·중·후의 실제 운영 흐름과 연결된다는 점**입니다. 교육생이 입력한 근거가 교수요원의 개입으로 이어지고, 수료 시 행동계획이 되며, 2개월 후 조직의 개선 자료로 돌아옵니다.

### 마지막 메시지

**농심튜터는 교육을 한 번의 행사에서 끝내지 않고, 현업 행동과 다음 교육 개선으로 이어지는 운영 체계로 바꿉니다.**

## 2. 시연영상 기본 전략

- 목표 길이: **약 6분 15초**
- 주인공: 교육생 1명과 교수요원 1명
- 핵심 질문: “교육생의 한 번의 입력이 교육 운영과 현업 적용으로 어떻게 이어지는가?”
- 편집 원칙: 기능을 나열하지 않고 **한 교육생의 시간 순 여정**으로 보여준다.
- AI 결과는 매번 표현이 달라질 수 있으므로 특정 문장을 약속하지 않는다. 대신 `목표`, `주제 묶음`, `원문 근거`, `후속질문`, `현업 미션`처럼 화면에서 반드시 확인할 구조를 대본에 넣는다.

## 3. 촬영 전 시연 데이터 준비

### 과정 준비

기존 운영 과정은 건드리지 않고 **촬영 전용 신규직원과정 1개**를 만든다. 같은 과정을 아래 순서로 날짜만 변경해 한 교육생의 시간이 흐르는 것처럼 촬영한다.

1. 시작일을 미래로 설정 → 입교 전 목표 촬영
2. 오늘이 시작일과 종료일 사이가 되도록 변경 → 실시간 질문·장표·보고훈련 촬영
3. 종료일을 오늘로 변경 → 수료 성찰·현업 미션 촬영
4. 종료일을 오늘보다 2개월 이상 전으로 변경 → 현업활용도 조사·전이 리포트 촬영

화면 전환 사이에 **“교육 중”**, **“수료일”**, **“2개월 후”** 타이틀 카드를 넣어 날짜 변경 과정을 숨기는 것이 아니라 시간 경과를 명확히 표현한다.

### 합성 입력 문안

실명·전화번호·사번 등 실제 개인정보는 사용하지 않는다.

#### 입교 전 목표 3문항

1. `민원 상담에서 조합원이 이해하기 쉽게 핵심을 먼저 설명하는 방법을 익히고 싶습니다.`
2. `긴장하면 보고 내용이 길어지고 결론이 늦어지는 점이 가장 어렵습니다.`
3. `결론-근거-조치 순서로 1분 안에 보고할 수 있으면 성공이라고 느낄 것 같습니다.`

#### 실시간 질문과 응답

- 질문: `조합원 민원을 접수한 직후 가장 먼저 확인해야 할 것은 무엇일까요?`
- 응답 예시:
  - `조합원이 원하는 것과 확인된 사실을 먼저 구분하겠습니다.`
  - `영향 범위와 긴급도를 먼저 확인하겠습니다.`
  - `관련 규정과 지금 가능한 조치를 함께 확인하겠습니다.`
  - `우선 사과하고 바로 담당자에게 넘기는 것이 좋다고 생각합니다.`

#### 장표

개인정보가 없는 촬영용 종이에 다음 내용을 크게 적는다.

- 제목: `민원 대응 3단계`
- 내용: `1. 경청  2. 사실 확인  3. 조치·공유`
- 하단: `조합원이 이해할 수 있는 말로 처리 순서와 예상 시간을 안내한다.`

#### 보고훈련

- 상황: `상사 부재 중 긴급 보고`
- 난이도: `보통`
- 최초 보고: `팀장님, 오늘 오전 접수된 민원 3건 가운데 1건은 처리가 지연되고 있습니다. 원인은 담당 부서 확인이 늦어진 것이며, 현재 영향 범위와 예상 처리 시간을 확인하고 있습니다. 우선 조합원에게 진행 상황을 안내하고 담당 부서의 회신 시점을 확정하겠습니다.`
- 꼬리질문 답변: `현재 직접 영향은 해당 민원 1건이며, 추가 확산 여부를 확인 중입니다. 담당 부서 회신 시간을 오늘 오전 중으로 확정할 수 있도록 요청드리겠습니다.`

#### 수료 성찰 3문항

1. `보고할 때 결론을 먼저 말하고 근거와 조치를 이어서 설명하게 되었습니다.`
2. `예상 질문에 필요한 수치와 영향 범위를 미리 확인하는 연습이 더 필요합니다.`
3. `매주 금요일 팀 회의 후 결정사항을 결론-근거-조치 한 줄로 정리해 공유하겠습니다.`

#### 2개월 후 조사

- 적용 사례: `민원 접수 후 사실관계와 처리 예상 시간을 먼저 안내하고, 진행 상황을 한 번 더 공유했습니다.`
- 장애요인: `업무량·시간 부족`
- 필요한 지원: `상황별 보고 문장과 우수 사례를 팀에서 함께 연습할 시간이 필요합니다.`

**내레이션**

**조작**

1. 교수요원 화면 진입

3. 관제판 지표와 학습 여정 확인

**내레이션**

> 교수요원은 과정별 관제판에서 현재 교육 단계와 목표·참여·성찰 제출 현황을 확인합니다. 교육생은 별도의 앱 설치 없이 과정 코드나 입장 링크로 자신의 학습 여정에 참여합니다.

**확인해야 할 화면 증거**

- 목표·성찰·참여 지표

### 장면 4. 입교 전 목표 — 1:08~1:48

**시간 경과 카드**

- `입교 전`

**화면**

- 교육생 화면의 `나의 목표 세우기`
- 세 질문 중 핵심 장면만 빠르게 연결
- 마지막 답변 후 `AI로 정리하기`
- 로딩 상태를 1초 정도 보여준 뒤 결과로 점프 컷
- 목표 다짐문, 집중 포인트, 행동 미션과 `실제 AI 정리` 라벨 확인

**조작**

1. 준비한 세 답변 입력
2. `AI로 정리하기` 선택
3. 생성된 문장을 검토하고 저장

**내레이션**

> 입교 전, 교육생은 세 가지 질문으로 자신의 기대와 현업 고민, 성공 기준을 돌아봅니다. AI는 이 답변을 새로운 사실을 덧붙이지 않고 목표 다짐문과 행동 방향으로 정리합니다. 교육생은 내용을 직접 수정하고 자신의 목표로 확정합니다.

**강조 자막**

- `교육생 답변 → 목표 다짐문`
- `AI 초안 + 교육생 최종 확인`

### 장면 5. 실시간 답변 묶기와 후속질문 — 1:48~2:38

**시간 경과 카드**

- `교육 중`

**화면**

- 교육생들이 실시간 질문에 답한 상태
- 교수요원 `실시간 질문` 화면
- `AI로 묶기` 선택
- 실제 AI 분석 라벨, 주제 묶음, 원문 근거, 후속질문, 수업 개입안 순으로 확대

**조작**

1. 교수요원 화면에서 답변 현황 확인
2. `AI로 묶기` 선택
3. 한 주제 카드의 원문 근거 확인
4. 후속질문 영역 강조

**내레이션**

> 수업 중에는 여러 교육생의 답변이 실시간으로 모입니다. 교수요원이 ‘AI로 묶기’를 누르면 비슷한 관점과 놓치고 있는 관점이 주제별로 정리됩니다. 각 분석에는 어떤 답변에서 나온 내용인지 원문 근거가 함께 표시되고, 교수요원은 추천 후속질문을 바로 수업에 활용할 수 있습니다.

**강조 자막**

- `답변 요약이 아니라 근거 기반 묶기`
- `원문 근거 · 후속질문 · 수업 개입안`

### 장면 6. 팀 장표 분석 — 2:38~3:18

**화면**

- 교육생 모바일 화면에서 장표 사진 업로드
- 교수요원 화면에서 업로드된 장표 확대

**조작**

1. 촬영용 장표 이미지 업로드
2. 교수요원 `팀 장표` 화면으로 전환
3. 장표 전체화면 확인
4. 팀별 AI 분석 실행

**내레이션**

**촬영 주의**
