# 농심튜터 v3

농협 교육의 목표–참여–수료 성찰–현업 적용을 하나의 데이터 흐름으로 보여주는 심사용 React 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

시연 과정 코드는 `NH-2480`입니다.

과정 코드 없이 교수요원으로 입장할 때 사용하는 로컬 시연 관리자 비밀번호는 `nh1234`입니다.

## 구현 기능

- 교육생 홈: 고정 목표 카드, 현재 단계 기반 오늘의 미션, 즉시 완료 상태 반영
- 교수요원 무코드 관리자 진입, 여러 과정 보존·선택, 과정명/기간/유형별 코드 발급
- 직급별 리더십과정 M급·3급·4급·5급 구분
- 교수요원 주관식·객관식 실시간 질문 생성과 객관식 자동 집계
- 교육생 모듈별 팀 장표 사진 업로드
- 교수요원 팀별 장표 전체화면 발표와 팀별·전체 AI 분석
- 과정 개설 전용 화면과 농협교육원 통합관리앱 연결
- 유형별 순차 과정 코드: 농협이념 `NH-1001~`, 리더십 `NH-2001~`, 신규직원 `NH-3001~`, 직무 `NH-4001~`
- 등록 과정 검색, 연도·유형·상태 필터, 운영/종료 분리, 페이지당 10개 목록
- 등록 과정명·직급·교육기간 수정과 2단계 삭제 확인
- 교수요원 관제판: 목표·성찰·사후조사·참여·AI 주제 지표와 추천 질문
- AI 근거 리포트: 요약, 주제 묶음, 실제 근거 원문, 행동 제안, 후속 질문
- QR 입장 카드와 교육생 링크 복사, URL 역할·코드 자동 입력
- 답변별 4종 반응 및 반응 수 기반 우선순위
- 팀 장표 업로드용 mock OCR adapter와 구조화 요약
- 신규직원 보고 롤플레잉 상황 5종과 난이도 3종
- 교육 종료 10초 후 사후조사 알림 데모
- 과정 성과 리포트 JSON/CSV 다운로드
- localStorage 기반 시연 데이터 유지
- 390px 모바일 반응형 UI

## 본선 발표용 시연 흐름 5단계

1. 교수요원이 `NH-2480` 관제판에서 과정 진행률과 추천 질문을 확인하고 QR 입장 링크를 복사합니다.
2. 교육생이 링크로 입장해 오늘의 미션에서 목표를 작성하고, 고정 목표 카드와 완료 상태 변화를 확인합니다.
3. 교육생 답변에 반응을 추가한 뒤 교수요원이 AI 분석을 실행하여 핵심 주제·근거 원문·후속 질문을 확인합니다.
4. 팀 장표 사진의 mock OCR 요약과 신규직원 보고 롤플레잉 코칭을 시연합니다.
5. 수료 성찰로 현업 미션을 만들고, 사후조사 알림과 응답 데이터를 JSON/CSV 성과 리포트로 내보냅니다.

## 배포 전 참고

현재 AI/OCR은 API 키 없는 심사용 데모 로직입니다. 실제 서비스에서는 서버 프록시와 환경변수 기반 API 연동으로 교체해야 합니다.
